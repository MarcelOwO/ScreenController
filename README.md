# ScreenController

A c++ application using cmake as the build system. The app is setup as a bluetooth peripheral and should be controlled with this Project: https://github.com/MarcelOwO/BackpackControllerApp

This application basically runs as a fullscreen desktop application that should be controlled via a remote device using the previously mentioned app.

Project is currently still wip.

## About

The goal of this project was to learn more about cpp and how make applications. From using tools like cmake, configuring my editor and using the various build tools.
